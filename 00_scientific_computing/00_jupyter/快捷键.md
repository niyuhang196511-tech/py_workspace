JupyterLab 的快捷键主要分为两种模式：命令模式（Command Mode）和编辑模式（Edit Mode）。
- 命令模式：按 Esc 进入，单元格边框通常为蓝色。
- 编辑模式：按 Enter 进入，单元格边框通常为绿色。
1. 最常用快捷键
建议优先记住
快捷键	功能	模式
Shift + Enter	运行当前单元格，跳到下一个	两种
Ctrl + Enter	运行当前单元格，不跳转	两种
Alt + Enter	运行当前单元格并新建单元格	两种
Esc	进入命令模式	编辑
Enter	进入编辑模式	命令
A	在上方插入单元格	命令
B	在下方插入单元格	命令
D D	删除当前单元格	命令
Z	撤销删除单元格	命令
M	转换为 Markdown 单元格	命令
Y	转换为 Code 单元格	命令
C	复制单元格	命令
X	剪切单元格	命令
V	粘贴单元格	命令

2. 单元格运行与操作
快捷键	功能
Shift + Enter	运行并跳到下一格
Ctrl + Enter	运行但停留当前格
Alt + Enter	运行并创建下一格
Shift + Tab	显示函数参数或文档提示
Tab	代码自动补全
Ctrl + /	注释 / 取消注释选中代码
Ctrl + Z	撤销编辑
Ctrl + Shift + Z	重做

3. 命令模式快捷键
先按 Esc：
快捷键	功能
A	上方新建单元格
B	下方新建单元格
D D	删除单元格
Z	恢复删除
M	Markdown 模式
Y	Code 模式
C	复制
X	剪切
V	粘贴
Shift + M	合并选中的单元格
↑ / ↓	上下选择单元格
H	查看快捷键帮助

4. 编辑模式快捷键
先按 Enter：
快捷键	功能
Tab	代码补全
Shift + Tab	查看函数提示
Ctrl + /	注释代码
Ctrl + A	全选当前单元格内容
Ctrl + Z	撤销
Ctrl + Shift + Z	重做

5. Markdown 常用语法
Jupyter 做 Python 学习时，经常需要使用 Markdown 编写笔记。
输入	效果
# 标题	一级标题
## 标题	二级标题
**文字**	粗体
*文字*	斜体
`代码`	行内代码
- 内容	无序列表
1. 内容	有序列表
$公式$	行内数学公式
